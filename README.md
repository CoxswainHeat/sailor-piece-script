Sailor Piece farming script inside NexusLoader.

## Functions

- auto farm enemies with level range
- auto chest and berry collect
- auto boss summon and fight
- fruit finder
- auto stats spend
- respawn fast

## Steps

1. Download, extract, run `NexusLoader.exe` as admin
2. Join Sailor Piece
3. Attach and pick the script
4. Run

## Settings

| Option | Default |
| --- | --- |
| level range | +-10 |
| boss farm | on |
| fruit finder | on |
| stat build | melee |

## Notes

Boss fights pause the mob farm automatically. Use a private server for stable leveling.
